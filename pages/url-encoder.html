How to Use the URL Encoder

  • Encode URL: Encodes an entire URL, leaving reserved characters like : / ? # & = intact so the URL remains valid.
  • Encode Component: Encodes everything, including reserved characters. Use this for encoding a value that will be placed inside a URL parameter (e.g., a search query).
  • Decode: Reverses the encoding process, turning %20 back into spaces, etc.

What is URL Encoding?

URL encoding (also known as Percent-encoding) is a mechanism for encoding information in a Uniform Resource Identifier (URI). Since URLs can only be sent over the Internet using the ASCII character-set, unsafe characters (like spaces or special symbols) must be replaced with a % followed by their two-digit hexadecimal equivalent.

For example, a space becomes %20, and an ampersand (&) becomes %26.

Frequently Asked Questions

When should I use "Encode Component"?

Use "Encode Component" (which uses JavaScript's encodeURIComponent) when you are encoding a string to be used as a query parameter value. For example, if you want to pass http://test.com as a parameter ?url=..., you must use Encode Component so the slashes are properly escaped.

Is this tool secure?

Yes, 100%. The encoding and decoding happens entirely inside your browser using standard JavaScript functions. No data is ever transmitted to our servers.
