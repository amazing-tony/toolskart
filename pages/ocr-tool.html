How Optical Character Recognition (OCR) Works

OCR uses computer vision and neural networks to recognize character shapes, glyphs, and typography within bitmap images and converts them into searchable, editable Unicode text.

Is my uploaded document private?

Yes, 100%. All optical character recognition is executed directly in your web browser using WebAssembly and Web Workers. Your files are never sent to any remote server.

What file formats are supported?

You can upload all standard image types including PNG, JPG, JPEG, WEBP, BMP, and GIF, as well as scanned PDF files.

How can I improve OCR accuracy?

For highest accuracy, use sharp, high-contrast images without glare or motion blur, and select the correct language matching the document text.
