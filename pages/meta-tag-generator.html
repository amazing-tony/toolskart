What are Meta Tags?

Meta tags are snippets of HTML code that describe a page's content. They don't appear on the page itself, but only in the page's source code. Search engines like Google use meta tags to help understand what the page is about.

Open Graph (OG) tags are used by Facebook, LinkedIn, and other social networks to display a rich preview (image, title, description) when someone shares your link.

Twitter Cards work similarly to Open Graph tags but are specific to Twitter.

Frequently Asked Questions

Are meta keywords still important?

Google officially announced in 2009 that they do not use the meta keywords tag for web ranking. However, some smaller search engines might still use them, and they can be useful for internal site search engines. We include them for completeness, but title and description are far more critical.

What is a Canonical URL?

The canonical tag tells search engines which version of a URL you want to appear in search results. It prevents duplicate content issues if your page can be accessed via multiple URLs (e.g., with or without 'www', or with tracking parameters).

What do Index and Follow mean?

"Index" tells search engines to add your page to their database. "Noindex" tells them to exclude it. "Follow" tells crawlers to follow the links on that page to discover new pages. "Nofollow" tells them to ignore the links.
